# Cozy Asia listing photo selection policy

This is the default mandatory order for Telegram property albums.

1. **Facade first.** Use the strongest bright daytime exterior view of the actual house or villa. If the owner supplied no exterior photo but supplied a video, extract the best clean frame from that video. Never fabricate an exterior or use another property.
2. **Living room and kitchen next.** Prefer bright, wide, attractive angles that explain the main open-plan space. Put the strongest living-room / kitchen-living view before narrow detail shots.
3. **Dining and secondary common-area angles after that.** Keep only views that add useful spatial information.
4. **Bedrooms after the common areas.** Show the best master-bedroom angle first, then other bedrooms. Avoid repetitive angles unless needed to prove a separate room.
5. **Bathroom / toilet last.** The final album image should be the best clean bathroom or toilet view.

Exclude weak or unattractive images when stronger alternatives exist: dark patio or fence shots, isolated outdoor furniture, empty corners, drawers, cutlery, dishes, appliances, bedside tables, and other technical close-ups. Selection priority is: attractive → bright → wide → representative → non-repetitive.
