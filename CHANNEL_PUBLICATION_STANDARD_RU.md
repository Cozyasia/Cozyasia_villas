# Постоянный стандарт публикаций Cozy Asia

Дата фиксации: 2026-09-21.

Этот файл является обязательным правилом для всех будущих публикаций, исправлений, one-shot runtime-пакетов и массовых стандартизаторов в двух Telegram-каналах Cozy Asia.

## 1. Жёсткая маршрутизация ботов по каналам

### Большой канал

Канал: `@samuirental`

Единственный допустимый бот для всех CTA:

`@cozy_asia_bot`

- заявка по конкретному лоту: `https://t.me/cozy_asia_bot?start=rent_<LOT>`
- подбор других вариантов: `https://t.me/cozy_asia_bot?start=search`

### Маленький канал вилл

Канал: `@arenda_vill_samui`

Единственный допустимый бот для всех CTA:

`@Cozyasia_villa_bot`

- заявка по конкретному лоту: `https://t.me/Cozyasia_villa_bot?start=rent_<LOT>`
- подбор других вариантов: `https://t.me/Cozyasia_villa_bot?start=search`

**Запрещено смешивать ботов между каналами.** Бот выбирается по целевому каналу, а не по токену/аккаунту, который выполняет публикацию.

`rent_<LOT>` обязан совпадать с номером лота, показанным в заголовке поста.

## 2. Формат описания

После строки `💬 ОПИСАНИЕ` само описание объекта оформляется как настоящий Telegram `blockquote`, а не символом `>` и не обычным абзацем.

Это правило относится ко всем новым постам обоих каналов.

## 3. Нижний блок публикации

Порядок элементов неизменный:

1. CTA конкретного лота / `ЖМИ ЗДЕСЬ` со ссылкой `start=rent_<LOT>`.
2. После строки `👉 ЖМИ ЗДЕСЬ 👈` — **две пустые строки**.
3. `Оператор: @cozy_asia`.
4. На следующей строке: `🔎🏡 ПОДОБРАТЬ ДРУГИЕ ВАРИАНТЫ — НАПИСАТЬ БОТУ 🤖` со ссылкой `start=search`.
5. Одна пустая строка.
6. Хэштеги — только в самом низу поста.

Эталон структуры:

```text
[ОСТАВИТЬ ЗАЯВКУ / Premium CTA]
👉 ЖМИ ЗДЕСЬ 👈


Оператор: @cozy_asia
🔎🏡 ПОДОБРАТЬ ДРУГИЕ ВАРИАНТЫ — НАПИСАТЬ БОТУ 🤖

#АрендаСамуи ... #CozyAsia
```

## 4. Сохранение ручного форматирования

При исправлении уже опубликованных постов нельзя заново собирать текст, если требуется только поменять URL.

Нужно менять только `MessageEntityTextUrl.url`, сохраняя без изменений:

- текст;
- переносы и пустые строки;
- `MessageEntityBlockquote`;
- жирное форматирование;
- Premium Custom Emoji;
- фотографии и media group;
- остальные ссылки.

## 5. Фотографии

Если у объекта больше 10 пригодных фотографий:

- в Telegram публикуются ровно 10 лучших обычных фото объекта;
- фото + полное описание остаются одной медиагруппой;
- дополнительные Telegram-альбомы не создаются;
- остальные пригодные фото идут в публичную папку Google Drive;
- в посте присутствует ссылка `📸 Дополнительные фото`;
- инфографика, прайс-карточки, телефоны, рекламные баннеры, карты, логотипы и дубли в публичный набор фото не входят.

## 6. Контакты собственника

Имя, телефон, WhatsApp, LINE, Facebook-профиль и другие контакты собственника сохраняются только во внутреннем каталоге/таблице Cozy Asia.

В публичный Telegram-пост контакты собственника не выводятся.

## 7. Предпубликационная проверка

Перед отправкой нового поста необходимо проверить:

- целевой канал;
- правильного бота для этого канала;
- точное совпадение `rent_<LOT>` с номером лота;
- наличие `start=search` на том же правильном боте;
- blockquote у описания;
- порядок CTA → пустые строки → оператор → поиск → хэштеги;
- геолокацию;
- отсутствие контактов собственника в публичном тексте;
- стандарт 10 фото + Drive при наличии дополнительных кадров.

Модуль `channel_publication_policy.py` содержит машинно-проверяемую часть этого стандарта.
